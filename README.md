## 💻 Projects Completed

### 1. QuoteFlow – Inspirational Quotes Application

**Repository:** [CodeAlpha_QuoteFlow](https://github.com/BetterCallShiv/CodeAlpha_QuoteFlow)

QuoteFlow is a modern Android application designed to provide users with an elegant experience for discovering and saving inspirational quotes.

**Key Features:**
- Browse inspirational quotes.
- Navigate between quotes using swipe gestures.
- Save and manage favourite quotes.
- Smooth animated transitions.
- Material 3 interface using Jetpack Compose.
- System dark mode support.
- Android Dynamic Colors support.
- Persistent local storage using Room Database.

**Technologies Used:**
- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- Gradle Kotlin DSL

**Learning Outcomes:**
- Modern declarative UI development.
- Interactive Android interfaces.
- Gesture-based navigation.
- Local database management.
- UI animations and transitions.
- Dynamic theming.

### 2. FlashCard – Learning and Revision Application

**Repository:** [CodeAlpha_FlashCard](https://github.com/BetterCallShiv/CodeAlpha_FlashCard)

FlashCard is a lightweight Android application designed to help users create, organize, and study flashcards for learning and revision.

**Key Features:**
- Create custom flashcards.
- Edit existing flashcards.
- Delete unwanted flashcards.
- Interactive study mode.
- Reveal answers while studying.
- Offline functionality.
- Persistent local storage.
- Optimized application builds.

**Technologies Used:**
- Java
- XML
- Material Components for Android
- Gson
- SharedPreferences
- ProGuard/R8

**Learning Outcomes:**
- Traditional Android application development.
- XML-based UI development.
- CRUD operations.
- Local data management.
- JSON serialization and deserialization.
- Application optimization.
